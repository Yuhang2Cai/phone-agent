# AG07 配对发布与回退

本入口限定单Agent、单Spring及本任务独立双库/Chroma，性能容量未经确认。AG06 PD01—05延期，原10%门槛、历史失败和未测范围保留。不能据本流程宣称C5/C20容量或生产放量。

## 预检与产物

使用同批隔离构建的Agent ZIP、Spring JAR和已固定镜像。发布时不从动态工作区build。清单记录双仓完整commit/tree、每份产物字节数/SHA256、完整迁移路径和SHA256、契约摘要、非秘密配置摘要、Python/JDK/镜像版本、两侧实际开关、目标ID及秘密名称/存在性。当前Spring源码目标Java17，实际隔离构建JDK21.0.8；编译器版本、class目标版本与运行JDK须分别核查，不能因历史Dockerfile使用17就认定相同。

`PYTHONPATH`显式指向同批隔离Agent源码，在Phone隔离目录执行 `python -m scripts.operations.release --manifest <公开清单> --observed <公开观察>`。返回preview_valid只是格式和文件一致，不授权执行。文件输入无法证明现场隔离；CLI没有apply选项。实际编排须由受信适配器现场核精确身份，使用 `enter_maintenance`、`apply_release` 或 `rollback_release`，不能把手写observed当现场结果。

`docker-compose.operations.yml`仅消费固定镜像、私有env文件和回环端口，无build、旧库默认值或自动restart。配置生成不得输出私有env；未经维护隔离验证不能直接up。原 `docker-compose.integration.yml`、Dockerfile保留历史范围，不作为新版本自动启动脚本。

## 维护与发布顺序

1. 核双仓版本、实际目标和产物；拒绝未知字段、错SHA、其他owner/ID/卷、非回环端口、多副本、缺秘密及成对开关不匹配。
2. 保留已验证备份/回退点；受信部署器关闭新普通输入，保留原receipt/目录/控制核查。入口无可核查断流能力时只能预检。
3. 最多120秒排空普通/控制/同步工作及后台写者。未知写先查原执行键；任何未知、计数缺失或超时都保持关闭，不重发、不强杀。
4. 正常停止全部写者，建立本次双库/索引一致备份。源前后水位和摘要不变、备份完整验证通过才签发/消费一次维护凭证；失败凭证不可重复使用。
5. 一次切换完整配对产物。启动检查必须包括Agent `/internal/v2/health`及服务身份、依赖就绪、原receipt/确认/恢复预算/业务事实核查。Agent健康响应中的schemaVersion=2.0不是当前任务协议开关，不据此固定Spring为2.0。实际任务2.2/2.3按双方受控配置及持久版本匹配。
6. 通过业务回读后才恢复准入。部分切换、读取失败或超时不自动回退、重试、清库或再次发业务；保留现场和首次失败。

## 回退与验收边界

回退只接受Agent `8eed53203441a4c72a0ff624a094bad8d871a529`、Phone `e6877e2fe838ac20c7f2ac2eeaae0f09883b2a34`配对基线。AG07不新增业务schema，完整历史迁移仍须核对。先在新私有克隆库证明旧应用可读新状态、未知写仍核原键、旧确认不复活、预算不重置。只回退应用与兼容配置，不降级数据库、不用备份覆盖源库。

AG06没有AG07维护开关。回退适配器须保持外层入口关闭和独占调用者，旧应用只受理有界验证请求；不能调用不存在的管理接口假称维护已开启。

AG07-05只验证脚本、守卫和精确源码。受信进程/容器适配器、真实前进→回退→返回候选各一次及业务恢复事实在AG07-07统一验收。尚未执行不能写生产可用；无真实入口断流机制的生产环境继续限预检。
