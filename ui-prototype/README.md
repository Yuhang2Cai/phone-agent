# 饭搭子 AI 可点击原型

在桌面浏览器直接双击或打开 `index.html`。推荐用开发者工具的移动端视图，设为 **390 × 844**。

## 人工验收流程

1. 打开页面，输入任意手机号和验证码，点击“登录并开始点餐”，应进入首页。点击“注册”可进入注册页，填写昵称后点击“注册并开始点餐”，应回到首页；在“我的”中检查昵称已更新。
2. 点击首页商家卡片进入菜单；点击任一“+”，在规格弹窗选择规格、加料并加入购物车。菜单底部购物车条应更新数量与金额。
3. 点击购物车条，使用“+ / −”调整数量，点击“去结算”；选择地址并“提交订单”。在确认卡片分别试一次“取消”和“确认支付”。
4. 确认支付后，模拟支付页点击“支付 ¥…”，应进入订单详情。点击“推进订单状态”数次，检查时间线依次显示商家接单、骑手取餐、正在配送、已送达。
5. 从底部“订单”查看订单列表并进入详情；从“我的”进入地址管理，点击“新增收货地址”，填写标签和详细地址并保存。新地址应出现在列表中，且已自动设为当前地址；在自动化设置中开关自动确认。
6. 点击任意页面的 AI 浮球。输入“帮我点一份不辣的面”，点击发送，检查事件依次显示：解析意图、搜索商家、查询菜品、构建购物车、校验订单、等待确认。随后应出现包含商家、菜品、口味、地址和金额的确认卡片；点击“确认订单”后应更新为“订单已确认”，另一次演示点击“取消”应显示已取消状态。
7. 在 AI 助手中点击“🎙”，输入框应回填本地模拟识别文本；点击“⛶”应在全屏与半屏助手间切换。
8. 打开浏览器开发者工具的 Console，按以上流程点击，确认没有 JavaScript 错误。

## 说明

数据仅保存在页面运行内存中；刷新页面会重置购物车、订单和自动化状态。没有后端连接或远程资源。
