# 饭搭子 AI 旧版 HTML 可点击原型

本目录是历史/实验 HTML 原型，不是当前 Android UI 的视觉基准，也不作为 Android UI 验收依据。当前 Android UI 必须直接依据 `docs/ui-redesign.md` 及其引用的设计稿实现；本原型仅保留作交互思路参考。

在桌面浏览器直接打开 `index.html`，推荐使用移动端视图，分别检查 **360dp、393dp、412dp** 宽度。

## 历史演示流程

1. 点击“跳过登录，先看看”，验证访客可浏览首页、搜索和商家菜单。
2. 从首页搜索框进入搜索页；点击商家卡片进入菜单，选择可用菜品并加入单商家购物车；点击售罄菜品确认按钮不可用。
3. 从购物车进入结算；没有地址时确认按钮被阻断；进入地址管理添加地址后返回结算。
4. 创建待支付订单，进入模拟支付；返回修改应回到结算，支付成功后进入订单详情和配送时间线。
5. 从订单 Tab 查看全部订单，点击“推进配送状态（演示）”验证状态变化；从“我的”进入地址管理和自动化设置。
6. 打开 AI 助手，发送“清淡午餐，30 元以内”，验证用户语言的执行进度、候选订单、修改和确认；确认后应创建待支付订单并进入模拟支付。
7. 在 AI 助手中点击录音按钮验证文本回填；点击全屏按钮验证半屏/全屏切换；关闭后重新打开验证会话保留。
8. 刷新页面验证原型状态可恢复；使用 360dp、393dp、412dp 及放大字体检查文字、底部导航、AI 浮球和购物车栏不互相遮挡。
9. 打开浏览器开发者工具 Console，按以上流程操作，确认没有 JavaScript 错误。

## 说明

数据仅保存在浏览器本地 localStorage；没有后端连接或远程资源。原型中的登录、支付、AI 执行和配送推进均为可重复的本地演示。
