# 02: 首页、搜索与商家浏览

**What to build:** 用户可以从新首页搜索商家或菜品，进入搜索结果和商家菜单；首页采用设计稿确定的视觉主体与搜索框交互，并正确呈现加载、空结果、网络错误和无地址状态。

**Blocked by:** 01: Android UI 壳、登录与访客导航

**Status:** in-review

- [ ] 首页实现地址、通知、搜索框、AI 点餐卡片、“再来一单”快捷建议和附近好店。
- [ ] 首页不展示独立历史订单卡片；无地址时仍允许搜索和 AI 推荐。
- [ ] 搜索框进入独立搜索页并自动聚焦，搜索页支持关键词、筛选和商家结果。
- [ ] 搜索页区分 Idle、Searching、Results、Empty、NetworkError 和 AuthRequired。
- [ ] 搜索结果进入商家菜单，不直接创建购物车或订单。
- [ ] 页面使用真实或 Fake API 接入现有商家数据，并覆盖 ViewModel/Repository 测试。
- [ ] 提供首页到商家菜单的 Maestro 浏览流程。
