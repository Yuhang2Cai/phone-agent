# 03: 地址管理、我的页面与自动化边界

**What to build:** 用户可以在“我的”中管理收货地址并配置自动化策略；没有有效地址、默认地址或金额超出限制时，自动下单会被明确阻断。

**Blocked by:** 01: Android UI 壳、登录与访客导航

**Status:** historical

- [ ] 访客进入用户相关功能时要求登录，登录成功后返回原操作。
- [ ] 地址页支持加载、空列表、新增、编辑、删除和设置默认地址。
- [ ] 默认地址不能直接删除；删除和编辑提交中禁止重复操作。
- [ ] 结算页选择地址只影响当前订单，不修改长期默认地址。
- [ ] 设置页只展示面向用户的“AI 助手”说明，不展示 Agent、模型、API Base URL 或 API Key。
- [ ] 区分本次自动下单和长期自动下单；长期模式需要默认地址和最高金额。
- [ ] 覆盖无地址、失效地址、金额超限和授权阻断状态的测试。
