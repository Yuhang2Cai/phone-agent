# 06: AI 助手与确认下单

**What to build:** 用户可以在首页、搜索、商家和订单页面打开 AI 助手，输入或录音表达需求，看到用户语言的执行进度、候选订单、修改和确认；确认后进入待支付订单和模拟支付流程。

**Blocked by:** 05: 待支付订单、模拟支付与配送时间线；03: 地址管理、我的页面与自动化边界

**Status:** historical

- [ ] AI 助手以半屏/全屏底部面板呈现，用户只看到“AI 助手”和自然语言进度。
- [ ] 支持文字输入、录音后识别、结果编辑、发送、执行中、等待确认和错误状态。
- [ ] 执行进度使用“正在理解你的需求、正在寻找附近好店、正在查看菜品、正在准备订单”等用户文案。
- [ ] 候选订单展示商家、菜品、规格、数量、地址、配送费、优惠和总金额。
- [ ] 支持自然语言修改以及数量、规格和地址的直接修改；修改后重新校验。
- [ ] AI 确认后创建待支付订单，再进入模拟支付，不绕过普通订单流程。
- [ ] 页面切换或关闭面板后保留 AI 会话、事件和候选订单；返回键遵循全屏→半屏→关闭。
- [ ] 覆盖确认、修改、取消、无地址、价格变化、库存变化和会话恢复测试。
